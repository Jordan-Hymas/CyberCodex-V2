## Learn through original flag missions

Start with reading your first dispatch. Progress through filesystem discovery, data processing, permissions and multi-step command-line checkpoints. Each mission includes an explanation, syntax example, task, common mistake, understanding check and hints.

The beginner section contains 12 free missions. Intermediate and advanced sections contain 12 missions each and require an active paid plan. Capture each mission's personal flag to unlock the next.

## Your own environment

Sign in to create a private, saved environment for each mission. Commands update your own files, not other learners' files. Reset restores the mission and changes its flag; completed progress remains saved.

## What the terminal supports

This is a bounded teaching simulation, not a full Linux virtual machine. Type `help` for the implemented command set. Full Bash scripts, real process control, package installation, networking, service administration and kernel behavior are outside this release. Advanced here means composing the supported command-line tools; deeper Linux system-administration labs are future work.
