## Learn

rev reverses the characters on each line. It's a quick way to undo simple text obfuscation.

Attackers and puzzle-makers often hide strings with trivial tricks like reversing them. If text reads like gibberish that ends with &#123;REBYC, try rev.

## Example

```sh
echo olleh | rev     # prints: hello
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

reversed.txt contains a transmission sent backwards. Recover the flag. mirror.txt was a test transmission.

1. Reverse reversed.txt.

## Common mistake

rev does not reverse the entire file as one character sequence.
