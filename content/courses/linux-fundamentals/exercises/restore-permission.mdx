## Learn

Every file has permissions: read (r), write (w) and execute (x). If you can't read a file, chmod u+r gives you (the owner) read permission back.

ls -l shows permissions as a string like -rw-r--r--. The first three letters after the dash are the owner's. A dash means that permission is missing. Permission errors are among the most common problems on real systems, and fixing them is a basic admin skill.

## Example

```sh
ls -l secret.txt         # --w------- means no read permission
chmod u+r secret.txt     # give the owner read access
```

Example filenames illustrate syntax; inspect your mission files before running them.
