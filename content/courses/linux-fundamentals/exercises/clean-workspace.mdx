## Learn

rm removes files; rmdir removes an empty directory. In a real shell deletion is not a recycle-bin operation. Inspect exact paths before removing anything.

Cleanup is a good place to prefer precise commands. Inspect the directory before deleting, remove only the intended entries, then use rmdir as a check that nothing remains. A simulator reset can restore these fixtures, but real Linux deletion often cannot be undone.

## Syntax example

```sh
ls scratch
rm scratch/example.tmp
rmdir scratch
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Remove the two temporary files in staging, then remove the empty staging directory. Preserve keep.txt.

## Common mistake

A broad wildcard can match more files than intended. Never use deletion commands without understanding the target path.
