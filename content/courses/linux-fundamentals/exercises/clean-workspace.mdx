## Learn

rm deletes files and rmdir deletes empty directories. A glob like staging/*.tmp deletes just the temp files.

Deleting is permanent: there's no recycle bin. Be precise with globs, check with ls before you delete, and prefer rmdir for folders so you only remove them once they're empty.

## Example

```sh
ls build/*.tmp     # check first
rm build/*.tmp     # then delete
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Delete the temporary files in staging, then remove the empty staging folder. keep.txt must survive.

1. Check what's in staging.
2. Delete the .tmp files, then the empty folder. Leave keep.txt alone.

## Common mistake

A broad wildcard can match more files than intended. Never use deletion commands without understanding the target path.
