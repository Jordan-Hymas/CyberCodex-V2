## Learn

### Two kinds of path

There are two ways to write a path, and the difference is the first character.

- An absolute path starts with `/`. It's the full address from the root of the tree, so it points at the same file no matter where you are. Example: `/etc/hostname`.
- A relative path doesn't start with `/`. It's read starting from your working directory, so the same relative path can point at different files depending on where you stand. Example: `notes.txt` or `etc/hostname`.

### Reading a file without moving

You don't need to `cd` somewhere to read a file there. Give `cat` an absolute path and it reads the file from anywhere. Here we stay in the home directory the whole time.

```sh
pwd
cat /etc/hostname   # the system's name for this machine
cd /tmp
cat /etc/hostname   # same file from a different place
```

### One missing slash changes everything

`/etc/hostname` and `etc/hostname` look almost the same, but the second is relative. From your home directory it means `/home/user/etc/hostname`, a completely different file. If a mission hands you an absolute path, type the leading `/`.

```sh
cd
cat etc/hostname   # relative: this is /home/user/etc/hostname
```

### When to use which

Absolute paths are best in instructions, notes and scripts, because they work whoever runs them and wherever they are. Relative paths are shorter when you're already close to the file. Professionals use both all day.

## Command cheat sheet

- `cat /ABSOLUTE/PATH`: Read a file from anywhere.
- `cat RELATIVE/PATH`: Read a file starting from the current directory.

## New words

- **Absolute path**: a path starting with `/`. It means the same thing everywhere.
- **Relative path**: a path without a leading `/`, read from your working directory.

## Why it matters

Logs and config files live in fixed places like /var/log and /etc. Reading them by absolute path is something you'll do constantly.

## Your mission

A dispatch is waiting in /opt/academy. Read it without leaving your home directory.

1. Stay in your home directory (no cd needed).
2. Run cat /opt/academy/dispatch.txt.
3. Optional: run pwd to confirm you never moved.

## Common mistake

The leading slash matters. opt/academy/dispatch.txt (no slash) would look inside your current directory instead.
