## Learn

An absolute path works from any current directory. cat can read several files in order; a relative path instead starts from your current directory.

An absolute path begins at /. A relative path begins at your current working directory. Reading by an absolute path is useful in instructions and scripts when you want to be independent of where a terminal happens to start.

## Syntax example

```sh
cat /etc/example.conf
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Read /opt/academy/dispatch.txt without changing directory.

## Common mistake

A leading slash is meaningful; etc/example.conf and /etc/example.conf refer to different locations.
