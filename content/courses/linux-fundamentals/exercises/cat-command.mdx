## Learn

An absolute path starts with / and points to the same place no matter where you are. You can read a file anywhere by giving cat its absolute path, without moving.

So far you've used relative paths, which start from your current directory. Absolute paths start from the root /. They're handy in instructions and scripts because they always work, whatever directory the terminal happens to be in.

## Why it matters

Logs and config files live in fixed places like /var/log and /etc. Reading them by absolute path is something you'll do constantly.

## Example

```sh
cat /etc/hostname      # read a file by its absolute path
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

A dispatch is waiting in /opt/academy. Read it without leaving your home directory.

1. Stay in your home directory (no cd needed).
2. Run cat /opt/academy/dispatch.txt.
3. Optional: run pwd to confirm you never moved.

## Common mistake

The leading slash matters. opt/academy/dispatch.txt (no slash) would look inside your current directory instead.
