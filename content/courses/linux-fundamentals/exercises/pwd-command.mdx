## Learn

pwd (print working directory) shows exactly where you are in the filesystem, as a full path that starts with /.

The Linux filesystem is one big tree. The very top is the root, written as /. Whenever you type a filename without a leading /, Linux looks for it in the directory pwd shows. That's why the same command can read different files depending on where you're standing.

## Why it matters

When a command says "No such file", checking pwd is the first thing to do. Most of the time you're simply in the wrong place.

## Example

```sh
pwd         # prints something like /home/user
ls          # lists what's in that directory
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

You've been dropped into the field somewhere. Work out where you are, then read the coordinates file in that exact spot.

1. Run pwd. This mission does NOT start in your home folder.
2. Run ls to see what's here.
3. Read coordinates.txt right where you are.

## Common mistake

A path tells you where something lives. coordinates.txt here and /coordinates.txt at the root would be two different files.
