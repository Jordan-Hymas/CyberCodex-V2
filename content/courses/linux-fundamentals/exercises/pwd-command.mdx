## Learn

pwd (print working directory) shows exactly where you are in the filesystem, as a full path that starts with /.

The Linux filesystem is one big tree. The very top is the root, written as /. Your home directory, /home/user, is a branch of that tree. Whenever you type a filename without a leading /, Linux looks for it in the directory pwd shows. That's why the same command can work in one place and fail in another.

## Why it matters

When a command says "No such file", checking pwd is the first thing to do. Most of the time you're simply in the wrong place.

## Example

```sh
pwd         # prints something like /home/user
ls          # lists what's in that directory
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Confirm where you are, then read the coordinates file stored there.

1. Run pwd to see your current directory.
2. Run ls to see what's in it.
3. Read coordinates.txt with cat.

## Common mistake

A path tells you where something lives. coordinates.txt here and /coordinates.txt at the root would be two different files.
