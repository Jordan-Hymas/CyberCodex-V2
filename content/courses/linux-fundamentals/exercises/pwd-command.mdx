## Learn

pwd prints an absolute path. The slash at the start means the filesystem root. Your working directory determines how relative paths are interpreted.

Think of the filesystem as a tree with one root, /. Your home directory is one branch of that tree. pwd reports your current location without modifying anything. It is a useful first diagnostic when a filename you expected to exist cannot be found.

## Syntax example

```sh
pwd
ls
```

Example filenames illustrate syntax; inspect your mission files before running them.
