## Learn

A pipeline can combine selection, field extraction, and decoding. Inspect each stage separately if you are unsure what data it produces.

Complex pipelines are easier to debug incrementally. Run the first stage and inspect its output. Add a second stage and check the shape again. Decode only the payload, not the record label. If a stage outputs nothing, inspect that stage before adding more commands.

## Example

```sh
grep READY example.txt | cut -d : -f 2
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Checkpoint. /var/log/manifest holds encoded records as NAME:payload. Decode the payload of the record named exactly READY. Similar records and an old manifest are there to trip you up.

1. Find the record named exactly READY (look at what else starts with READY).
2. Cut out its payload and decode it, ideally in one pipeline.

## Common mistake

Including the READY: prefix in the base64 decoder input will not produce the intended message.
