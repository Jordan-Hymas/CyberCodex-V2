## Learn

&gt;&gt; adds output to the end of a file and keeps everything already there. A single &gt; would wipe the file first.

Logs and notes grow over time, so you almost always want &gt;&gt; when adding to them. Mixing up &gt; and &gt;&gt; is one of the most common ways people lose data on Linux.

## Example

```sh
echo "next entry" >> journal.log    # adds a line at the bottom
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

status.log says offline. Add a second line, restored, without losing the first.

1. Read status.log.
2. Append the word restored as a new line.
3. Check the file has both lines, then read reward.txt.

## Common mistake

Using &gt; instead of &gt;&gt; replaces the entire previous log.
