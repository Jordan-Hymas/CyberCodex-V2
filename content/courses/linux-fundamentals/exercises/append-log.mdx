## Learn

The &gt;&gt; operator appends output. It preserves existing content, unlike &gt;. A newline separates records in a text log.

Appending makes a log grow without rewriting its earlier records. echo normally adds a newline, so appended records become separate lines. If earlier content lacks a final newline, the next text may run into it; inspect the resulting file when formatting matters.

## Example

```sh
echo "next entry" >> sample.log
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Append restored as a second line in status.log, keeping the first line.

## Common mistake

Using &gt; instead of &gt;&gt; replaces the entire previous log.
