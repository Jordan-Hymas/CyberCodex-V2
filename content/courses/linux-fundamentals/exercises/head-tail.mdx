## Learn

head shows the first lines of a file and tail shows the last lines. Add -n NUMBER to choose how many.

Logs grow at the bottom, so the newest entry is always the last line. tail -n 1 gives you just that. head is handy for a quick peek at a file's format without printing all of it.

## Example

```sh
head -n 3 app.log     # first three lines
tail -n 1 app.log     # the very last line
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

dispatches.txt is a running log. The newest dispatch is always added at the bottom. Don't trust the header.

1. Peek at the top with head to see what kind of file it is.
2. Print only the newest (last) line.

## Common mistake

tail -n 1 selects one line, not one character.
