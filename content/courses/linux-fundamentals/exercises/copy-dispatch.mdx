## Learn

cp copies a file and leaves the original where it is. mkdir creates a new directory. A copy needs its destination directory to exist first.

A copy is a completely separate file with the same contents, so changing one later won't affect the other. cp won't create missing directories for you, so make the folder first with mkdir. This mission checks your filesystem: once the backup exists with the right contents, a reward.txt file containing your flag appears in your home directory.

## Why it matters

Backing up a file before you touch it is a habit that saves careers, especially when you're editing configs on a live system.

## Example

```sh
mkdir copies                      # create a folder
cp notes.txt copies/notes.txt     # copy a file into it
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Make a backup of the field report: create a backup directory and copy report.txt into it. Your flag appears in reward.txt once the backup is in place.

1. Run mkdir backup.
2. Run cp report.txt backup/report.txt.
3. Read the reward with cat reward.txt.

## Common mistake

Copying onto an existing file replaces its contents with no warning. Check the destination carefully.
