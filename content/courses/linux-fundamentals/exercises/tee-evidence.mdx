## Learn

tee writes its input to a file and also passes it on to the screen, so you can save evidence while still seeing it. ^ in a grep pattern means the line must start with that text.

When you investigate, keep exact copies of what you found. tee lets you save a pipeline's output without breaking the pipeline. Anchors like ^OK prevent accidental matches such as NOT OK.

## Example

```sh
grep ^ERROR app.log | tee errors.txt
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Save exactly the line from source.log that starts with OK into evidence.txt, and watch it print as you do. Lines that merely contain OK don't count.

1. Find the line that starts with OK (not lines like NOT OK).
2. Save exactly that one line to evidence.txt with tee.

## Common mistake

tee does not filter the input. Perform selection before tee if you only want selected records saved.
