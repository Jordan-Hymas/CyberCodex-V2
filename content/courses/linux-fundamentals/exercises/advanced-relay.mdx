## Learn

Combine discovery, filtering, decoding, and evidence preservation. Verify each stage rather than guessing a long command. There can be more than one correct sequence of commands.

A capstone brings discovery and transformation together. Keep an evidence trail: know where the source came from, what each pipeline stage changes, and where the final result is saved. Equivalent valid command sequences are accepted because the result matters more than one memorized solution.

## Example

```sh
find /opt/academy -type f
```

## Your mission

Final checkpoint. Several dispatch.dat files exist under /opt/academy. Use the ACTIVE one: select its RELEASE record, decode field 2, and save the decoded flag to /home/user/final.txt.

1. Find every dispatch.dat under /opt/academy and work out which is ACTIVE.
2. Decode the RELEASE payload from that file only, and save it to /home/user/final.txt.

## Common mistake

The final flag must also be saved at the requested path before the mission is complete.
