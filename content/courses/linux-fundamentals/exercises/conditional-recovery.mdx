## Learn

&& runs the next command only if the previous one succeeded, and || runs it only if the previous one failed. test -f file succeeds when the file exists.

Conditionals let a single line react to the system, which is the heart of scripting. command1 || command2 reads as "try this, otherwise do that".

## Example

```sh
test -f config.ini || echo missing
test -d logs && echo "logs exist"
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Write one line that creates restored.txt containing recovered, but only if missing.txt does not exist. Use test and ||.

1. Check what test -f missing.txt returns.
2. Chain it with || so the recovery only runs on failure.

## Common mistake

Do not judge success only by whether output was printed.
