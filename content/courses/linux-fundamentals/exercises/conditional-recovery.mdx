## Learn

&& runs the next command only after success. || runs it only after failure. test checks a condition and communicates through its exit status rather than printed text.

Commands communicate success with zero and other outcomes with nonzero status. && and || make later commands conditional on that status. test often prints nothing; silence is normal. The lab supports a small documented test subset rather than the whole shell expression language.

## Example

```sh
test -f sample.txt && echo present
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Use test and || to create restored.txt containing recovered when missing.txt does not exist.

## Common mistake

Do not judge success only by whether output was printed.
