## Learn

uniq removes repeated lines, but only when the repeats sit next to each other. sort first to bring duplicates together, then uniq -u keeps only the lines that appear exactly once.

This is a classic trap: uniq on an unsorted file misses duplicates that are far apart. sort | uniq is the standard pairing. -u shows lines that appear once, and -c counts how many times each appears.

## Example

```sh
sort names.txt | uniq -c     # count each name
sort names.txt | uniq -u     # names that appear only once
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

messages.txt is full of repeated messages. Exactly one line appears only once, and that's your flag. Some repeats are far apart.

1. Try uniq -u on the file directly and notice something's off.
2. Sort first, then keep only the unique lines.

## Common mistake

sort changes order. Do not use it when the original sequence carries meaning you must preserve.
