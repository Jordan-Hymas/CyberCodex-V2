## Learn

A pipe sends one command’s standard output to the next command’s standard input. It does not turn that output into filenames.

Standard input is a data stream consumed by a command. Standard output is the stream it produces. A pipe joins these streams. The right side receives the left side’s output as data, not as command-line arguments, which is why cat sample.log | grep READY needs no filename for grep.

## Syntax example

```sh
cat sample.log | grep READY
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Common mistake

Do not add a filename to the receiving command unless you intend it to read that file instead of the pipe.
