## Learn

This is a terminal: you type a command, press Enter, and Linux prints the result. Your first command is cat, which prints the contents of a text file to the screen. Reading a file with cat never changes it.

Every command starts with its name, followed by any arguments, separated by spaces. Here, cat is the command and the filename is its argument. The text before the $ (user@cybercodex:~) is the prompt. It shows who you are and where you are, and you don't type it. The ~ means your home directory, which is where every mission starts unless it says otherwise.

## Why it matters

Security work starts with reading: config files, logs, notes left on a system. cat is the quickest way to look inside a file.

## Example

```sh
cat notes.txt      # prints everything inside notes.txt
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Your home directory holds a file called dispatch.txt. Read it to find your first flag.

1. Type cat dispatch.txt and press Enter.
2. Find the flag in the output. It looks like CYBER&#123;...&#125;.
3. Highlight the whole flag with your mouse (it copies automatically) and paste it into the flag box.

## Common mistake

Don't type the $ or anything before it. That's the prompt, not part of the command. And don't run the flag as a command: paste it into the flag box.
