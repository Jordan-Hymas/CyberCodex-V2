## Learn

A terminal accepts commands and prints their results. cat reads a text file; it does not change that file. A flag is the proof you retrieve from a challenge, not a command to execute.

A command usually has a name followed by arguments, separated by spaces. Press Enter to run it and wait for the next prompt before typing another command. The prompt is not part of the command. cat writes file contents to standard output, which is what you see in the terminal.

## Syntax example

```sh
cat greeting.txt
```

Example filenames illustrate syntax; inspect your mission files before running them.
