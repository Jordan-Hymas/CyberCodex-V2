## Learn

find walks a directory tree. -name matches an entry name, not its contents. Quote wildcard patterns so the shell does not expand them first.

find searches names and metadata in a directory tree; grep searches file contents. Choosing the starting directory controls the search scope. A quoted -name pattern is interpreted by find rather than expanded by the shell before find starts.

## Example

```sh
find /home/user -name "*.txt"
```

Example filenames illustrate syntax; inspect your mission files before running them.
