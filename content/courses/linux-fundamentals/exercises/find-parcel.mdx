## Learn

find searches a whole directory tree for files by name, however deep they're buried. find /some/path -name parcel.txt prints every match.

Clicking through folders one at a time doesn't scale. find walks every folder below the path you give it. When find returns several matches, check each one, because files with the same name can mean very different things.

## Example

```sh
find /home -name "*.txt"        # every .txt file below /home
find /etc -name hosts           # files named exactly hosts
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

A parcel addressed to you is somewhere in the depot under /opt/academy. More than one parcel.txt is in there.

1. Use find to list every parcel.txt below /opt/academy.
2. Read them and keep the one addressed to user.

## Common mistake

A filename match does not mean the file contains the desired record. Inspect it after discovery.
