## Learn

cut pulls one column out of each line. -d sets the separator and -f picks the field number, so cut -d : -f 3 gives the third colon-separated field.

Lots of system files are colon-separated (like /etc/passwd). Combine cut with grep to pick a row first and then the column you need. Fields are counted from 1.

## Example

```sh
cut -d : -f 1 /etc/passwd           # every username
grep root /etc/passwd | cut -d : -f 7  # root's shell
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

manifest.txt lists shipments as id:status:payload. Extract the payload (field 3) of the shipment whose status is ready.

1. Look at the file to see its columns.
2. Select the ready row, then cut out field 3.

## Common mistake

If a delimiter appears inside a quoted value, this simple cut command still treats it as a delimiter.
