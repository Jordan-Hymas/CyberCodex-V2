## Learn

A relative path can climb up with .. before going back down. ../store/receipt.txt means "go up one level, enter store, then find receipt.txt".

This mission starts you inside /home/user/work. The . in a path means "here" and .. means "the parent directory", and they can appear anywhere in a path. If a path confuses you, resolve it one piece at a time: start at pwd, then apply each part in order.

## Why it matters

Relative paths keep commands short and portable. You'll see ../ in scripts, configs and exploits all the time.

## Example

```sh
cat ../notes.txt          # a file one level above you
cat ./notes.txt           # a file right here (same as notes.txt)
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

You're standing in the work directory. The receipt is in the store directory next door. Read it without using an absolute path.

1. Run pwd to confirm you're in /home/user/work.
2. Run ls .. to see the directories next to work.
3. Read the receipt with cat ../store/receipt.txt.

## Common mistake

../store is not /store. The first depends on where you are; the second always starts at the root.
