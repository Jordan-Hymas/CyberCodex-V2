## Learn

`export` sets a shell variable; $NAME expands its value in a later command. Single quotes preserve literal dollar signs, whereas double quotes permit expansion.

Variables let you name a reusable value. Referencing $PLACE expands that value in a later command. This teaching shell keeps HOME, USER, and PATH fixed and does not implement full shell scoping or word splitting. Use a separate command after export before using the new variable.

## Syntax example

```sh
export PLACE=/tmp
echo "$PLACE"
```

Example filenames illustrate syntax; inspect your mission files before running them.
