## Learn

A variable stores a value under a name. export DEST=/some/path sets it, and $DEST is replaced by that value in later commands.

Variables keep long paths and settings in one place. Use double quotes around "$DEST/file" so paths with spaces still work. In this lab, set the variable in one command and use it in the next.

## Example

```sh
export LOGS=/var/log
ls "$LOGS"
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Set DEST to /opt/academy/signal, then read the receipt through "$DEST/receipt". Careful: a similarly named folder exists.

1. Set the DEST variable to exactly /opt/academy/signal.
2. Read the receipt using $DEST.

## Common mistake

Single quotes around $PLACE print its name literally.
