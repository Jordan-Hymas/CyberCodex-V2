## Learn

cd (change directory) moves you to another directory. cd .. goes up one level, cd - jumps back to where you just were, and plain cd takes you home.

Your terminal remembers one current directory. After a cd, every filename you type is looked up from the new location. Directories inside directories are written with / between them, so stations/relay means "the relay folder inside stations". Use pwd or ls after moving if you want to check where you landed.

## Why it matters

Moving around the filesystem quickly is the core skill for every later mission and every real system you'll work on.

## Example

```sh
cd /tmp     # go to /tmp
pwd         # confirm where you are
cd -        # jump back to the previous directory
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Three stations, one message. Walk into the relay station, read its message, then head back home.

1. Run ls stations to see the three stations.
2. Move in with cd stations/relay (Tab completes the names).
3. Read message.txt, then run cd on its own to go home.

## Common mistake

cd doesn't print anything when it works. No output means success, so run pwd if you want to check.
