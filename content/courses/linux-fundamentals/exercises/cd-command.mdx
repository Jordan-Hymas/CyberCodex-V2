## Learn

cd changes your working directory. .. names its parent, and . names the current directory. cd by itself returns home.

The shell remembers one working directory. cd changes that shell state, so the next command resolves relative paths from the new location. cd - returns to the previous location in this simulator, while cd with no operand returns home.

## Syntax example

```sh
cd /tmp
pwd
cd -
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Common mistake

Changing directory does not display all files automatically. Follow it with pwd or ls if you need confirmation.
