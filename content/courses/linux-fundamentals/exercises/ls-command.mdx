## Learn

ls lists directory entries. Names beginning with a dot are hidden from its default view. ls -a includes them, and ls -l shows permissions and other details.

An option changes how a command works, while a path operand tells it what to inspect. Linux filenames are case sensitive. Hidden entries are a naming convention, not an access-control feature: if you know the name and have permission, you can read them.

## Syntax example

```sh
ls
ls -a
ls -l
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

## Common mistake

The dot at the beginning of a filename is part of its name. Listing a file does not automatically read its contents.
