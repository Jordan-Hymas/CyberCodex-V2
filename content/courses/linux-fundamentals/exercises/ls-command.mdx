## Learn

ls lists the files in a directory. Files whose names start with a dot (like .config) are hidden from a normal listing. ls -a shows everything, and ls -l shows details like permissions and size.

Options such as -a and -l change how a command behaves. Hidden files are just a naming convention to reduce clutter, not a security feature: anyone who knows the name, and has permission, can read them. Remember that filenames are case sensitive, so Notes.txt and notes.txt are different files.

## Why it matters

Attackers and admins both stash things in dotfiles. Always use ls -a when you're exploring a system.

## Example

```sh
ls          # normal listing
ls -a       # include hidden files (names starting with .)
ls -l       # long listing with permissions and sizes
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Something is hidden in your home directory. List everything, find the hidden dispatch and read it.

1. Run ls and notice that only readme.txt appears.
2. Run ls -a to reveal hidden files.
3. Read the hidden file with cat (keep the dot in its name).

## Common mistake

The dot is part of the filename, so cat dispatch won't work. Listing a file also doesn't show its contents; you still need cat.
