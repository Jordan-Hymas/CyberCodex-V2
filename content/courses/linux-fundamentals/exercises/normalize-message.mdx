## Learn

tr translates characters: tr A-Z a-z turns every capital letter into lowercase.

Normalizing text (same case, same separators) makes data easy to compare and search. tr reads from standard input, so feed it with a pipe or &lt;.

## Example

```sh
echo HELLO | tr A-Z a-z     # prints: hello
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Convert status.txt to lowercase and save the result as normalized.txt.

1. Feed status.txt into tr and translate uppercase to lowercase.
2. Save the output to normalized.txt.

## Common mistake

Passing a filename to tr does not make it read that file. Redirect or pipe the contents instead.
