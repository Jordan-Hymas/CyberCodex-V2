## Learn

diff compares two files line by line. Lines starting with &lt; come from the first file and lines starting with &gt; from the second.

diff is how you spot tampering, config drift and changes between versions. A line that was edited shows up as a &lt; and &gt; pair. A line that was only added shows up as a &gt; with no partner.

## Example

```sh
diff old.conf new.conf
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Compare before.txt and after.txt. One line was edited and one line was added at the end. The flag is on the added line, not the edited one.

1. Run diff and read every change.
2. Pick the line that was added, not the one that was edited.

## Common mistake

Do not include the diff marker when copying a recovered value.
