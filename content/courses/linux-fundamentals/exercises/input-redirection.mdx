## Learn

&lt; feeds a file into a command's standard input, as if you'd typed its contents. base64 -d &lt; file.b64 decodes without passing the filename as an argument.

Many tools read from standard input when no file is given. &lt; lets you plug any file into them, and it's the mirror image of &gt;. You'll use it with tools that only read stdin, and in scripts.

## Example

```sh
wc -l < access.log        # count lines read from stdin
base64 -d < data.b64      # decode from stdin
```

Example filenames illustrate syntax; inspect your mission files before running them.
