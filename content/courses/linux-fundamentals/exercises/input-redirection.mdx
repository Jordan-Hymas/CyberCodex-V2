## Learn

The &lt; operator connects a file to a command’s standard input. The command does not need to receive that filename as an argument.

Input redirection gives a command an already-open input stream. It is useful for tools that naturally read standard input. It differs from passing a filename: the command sees the stream rather than using an operand to choose the source. Here both forms can achieve the same count.

## Syntax example

```sh
wc -l < sample.log
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Common mistake

The arrow points from the file into the command. &gt; points output toward a destination file.
