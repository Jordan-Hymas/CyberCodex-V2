## Learn

Base64 turns any data into plain letters and numbers so it can travel safely through text systems. It's an encoding, not encryption: base64 -d turns it straight back.

Base64 text looks scrambled, often ends in = signs, and shows up constantly in security work (tokens, email attachments, malware). Recognising it and decoding it is a core skill.

## Example

```sh
echo aGVsbG8= | base64 -d     # prints: hello
base64 -d file.b64            # decode a whole file
```
