## Learn

base64 represents bytes with printable characters. Encoding is not encryption: anyone can decode it. -d reverses the encoding.

Base64 is a reversible representation useful for transporting bytes in text channels. Encoded data may include padding characters at the end. Decoding yields the original bytes; do not assume that encoded content is secret or safe merely because it looks unreadable.

## Example

```sh
echo demo | base64
```
