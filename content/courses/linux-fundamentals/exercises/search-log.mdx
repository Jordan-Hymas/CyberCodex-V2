## Learn

grep prints only the lines that contain your search text. It's the fastest way to find one line in a huge log. Matching is case sensitive unless you add -i, and you can search for a phrase by putting it in quotes.

Logs are written one event per line, so grep turns thousands of lines into the few you care about. Search for the most specific text you know. If you get several matches, read them and refine the search, for example by searching for a longer phrase.

## Example

```sh
grep ERROR app.log              # lines containing ERROR
grep "disk full" app.log        # search for a phrase
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Somewhere in /var/log/relay.log is the receipt that was ACCEPTED. Other receipts were voided. The log was rotated, so relay.log.1 holds last week's entries.

1. Search the current log for RECEIPT and read every match.
2. Narrow the search to the accepted receipt only.

## Common mistake

Case matters unless you select -i. The search pattern and filename are separate arguments.
