## Learn

man command and help command describe the supported syntax. The teaching shell documents its own subset; a full Linux machine may offer additional options.

Knowing how to discover syntax is more valuable than memorizing every option. Read the synopsis first, then try one option at a time on small fixtures. These built-in manuals describe supported simulator behavior. On an actual Linux system, man pages are more extensive and depend on installed software.

## Syntax example

```sh
help
man cat
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Read man ls, then locate the hidden file inside /opt/academy/helpdesk.

## Common mistake

Do not assume a command exists merely because you have seen it online. The lab explains unsupported commands.
