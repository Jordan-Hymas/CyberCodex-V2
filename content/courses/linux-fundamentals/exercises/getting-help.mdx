## Learn

You don't have to memorize every command. man COMMAND opens a command's manual, and help lists every command this lab supports.

Real professionals look things up constantly. Read a manual's first line to see the basic syntax, then try one option at a time. This lab's manuals describe its supported subset; on a full Linux system, man pages are longer and cover more options.

## Why it matters

Knowing how to find the answer is more valuable than memorizing it. Every tool you meet later will come with a manual.

## Example

```sh
help        # list every supported command
man cat     # read the manual for cat
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Use the manual for ls to learn how to show hidden files, then use that to find the hidden receipt in /opt/academy/helpdesk.

1. Run man ls and look for the option that shows hidden entries.
2. List /opt/academy/helpdesk with that option.
3. Read the hidden file by its full path.

## Common mistake

Not every command or option you see online exists here. If one isn't supported, the lab will tell you, so check man first.
