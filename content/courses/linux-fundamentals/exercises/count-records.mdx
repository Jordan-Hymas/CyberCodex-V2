## Learn

wc -l counts lines. Piping grep into wc -l counts how many lines matched.

Counting matches is everyday analysis: how many failed logins, how many dropped packets. Make sure your filter matches only what you mean, because one wrong match changes the answer.

## Example

```sh
grep ^FAIL auth.log | wc -l
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Count the lines in traffic.txt that begin with ACCEPT and write just that number to count.txt. Some lines contain ACCEPT without starting with it.

1. Filter to lines that start with ACCEPT.
2. Count them and save the number to count.txt.

## Common mistake

A file containing text without a final newline may have fewer newline characters than visible text records.
