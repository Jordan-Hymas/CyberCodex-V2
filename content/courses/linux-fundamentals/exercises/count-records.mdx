## Learn

wc -l counts newline characters. A pipeline can filter records first and then count only the accepted set. A final line without a newline changes that count.

Counting meaningful records begins with deciding what qualifies as a match. After filtering, wc -l counts newline characters. The lab returns a plain count so it can be stored or used as evidence. Real utilities may add a filename label when given a filename operand.

## Syntax example

```sh
grep OK sample.log | wc -l
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Count lines containing ACCEPT in traffic.txt and write the count to count.txt.

## Common mistake

A file containing text without a final newline may have fewer newline characters than visible text records.
