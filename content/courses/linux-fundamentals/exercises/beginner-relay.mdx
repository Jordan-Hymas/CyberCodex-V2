## Learn

Checkpoint time: no new commands, just everything from chapters 1 to 3 combined. Work methodically: get to the right place, look at everything there (including hidden files), then read what you find.

Investigations go faster when you split them into steps. First, where am I and where do I need to be? Second, what's here, including hidden entries? Third, which file is the one I want? Read the output carefully and separate the flag from the prompt and the other text.

## Why it matters

This is how real exploration works: navigate, enumerate, read. You'll repeat this loop on every machine you investigate.

## Example

```sh
cd /some/place     # go there
ls -a              # look at everything, hidden files included
```

Example filenames illustrate syntax; inspect your mission files before running them.

A parcel has been hidden somewhere in /opt/academy/relay/archive. Find it and recover its flag.

1. Move into /opt/academy/relay/archive.

3. Read the hidden parcel.
