## Learn

Navigation combines listing, path selection, and reading. Work step by step: locate the directory, inspect all entries, then read the candidate.

A discovery task is easier when you separate location, inspection, and content. First establish where you are. Next inspect candidate entries, including hidden names. Finally read the relevant file and distinguish its contents from the surrounding prompt and command output.

## Syntax example

```sh
pwd
ls -a
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Find the hidden parcel in /opt/academy/relay/archive and submit its flag.

## Common mistake

Copy only the flag, not leading text or a trailing prompt. A flag from a reset environment is no longer valid.

## Check your understanding

Can you reach the same parcel with both relative and absolute paths?

Capture the personal flag and submit it in the form. Use `help` or `man COMMAND` for supported syntax. A reset restores fixtures and replaces the flag while preserving earned completion.
