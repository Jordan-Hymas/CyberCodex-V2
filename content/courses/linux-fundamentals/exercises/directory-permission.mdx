## Learn

Execute permission on a directory controls traversal. Read permission permits listing names; these are distinct. A readable file cannot be reached through a directory you cannot traverse.

Directory x allows walking through a path component. Directory r allows listing entry names. On a real system, a directory can allow traversal without allowing a listing. This lab models owner permissions so you can observe the difference without changing your actual system.

## Syntax example

```sh
stat folder
chmod u+x folder
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Restore owner traversal on vault, then read vault/receipt.

## Common mistake

Adding read permission to a file does not fix a missing traversal bit on its parent directory.
