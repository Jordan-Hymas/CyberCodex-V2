## Learn

For directories, x means permission to enter (traverse) them. Without it you can't reach any file inside, even one you're allowed to read.

Directory permissions trip up even experienced admins: r lets you list a folder's names, and x lets you go through it. Fixing traversal is often the real answer to a Permission denied error on a file path.

## Example

```sh
ls -ld vault        # d rw- ... no x for the owner
chmod u+x vault     # allow entering it
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

The vault directory has lost its owner traverse permission. Restore it and read vault/receipt. The backup copy is stale.

1. Work out why vault/receipt can't be read.
2. Restore the missing directory permission, then read the receipt.

## Common mistake

Adding read permission to a file does not fix a missing traversal bit on its parent directory.
