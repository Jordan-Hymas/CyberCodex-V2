## Learn

A glob is a wildcard pattern the shell expands into matching filenames. *.txt means every name ending in .txt, so cat batches/*.txt reads them all in one go.

The shell expands the pattern before the command runs, so cat simply receives a list of files. * matches any characters except /, which means it never reaches into subfolders. ? matches exactly one character.

## Example

```sh
ls *.log           # every .log file here
cat report-?.txt   # report-1.txt, report-2.txt, ...
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

The batches folder mixes .txt batches with log files and an archive. The receipt is in one of the .txt batches directly inside batches.

1. Read every .txt file directly inside batches with one glob.
2. Ignore logs and anything in subfolders.

## Common mistake

Quoting the wildcard prevents shell expansion. Dotfiles require an explicit dot in the pattern.
