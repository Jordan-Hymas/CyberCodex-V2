## Learn

An unquoted * expands to matching names within one path component. A question mark matches one character. Dotfiles are not matched unless the pattern explicitly begins with a dot.

Globbing happens before a command runs. If three names match, the command receives three arguments. The wildcard is limited to a single directory component in this simulator. A pattern with no matches remains literal, so the command can report that no such file exists.

## Syntax example

```sh
ls /home/user/*.txt
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Common mistake

Quoting the wildcard prevents shell expansion. Dotfiles require an explicit dot in the pattern.
