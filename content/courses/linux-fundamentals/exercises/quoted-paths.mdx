## Learn

Quotes make a filename containing spaces one argument. Single and double quotes both group text, but single quotes also prevent variable expansion.

The shell splits unquoted text into arguments. Matching quotes preserve spaces inside one argument and are removed before the command receives it. Single quotes preserve the text literally. Double quotes preserve spaces while allowing variable references used in later lessons.

## Syntax example

```sh
echo "a phrase with spaces"
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Common mistake

Apostrophes inside single-quoted text end that quote. Choose double quotes when appropriate.
