## Learn

The shell splits what you type into separate words at spaces. To use a filename that contains a space, wrap it in quotes so it stays one argument.

Without quotes, cat shift notes.txt asks for two files: shift and notes.txt. Quotes keep the whole name together, and the shell removes them before cat sees the name. Double quotes and single quotes both work for this. Single quotes are completely literal, which matters once you meet variables.

## Why it matters

Real systems are full of awkward filenames, especially anything copied from Windows or macOS. Quoting correctly prevents some nasty mistakes.

## Example

```sh
cat "my report.txt"      # one file whose name has a space
cat my report.txt        # two files: my and report.txt
```

Tab completion can add a backslash before the space for you. That works too.
