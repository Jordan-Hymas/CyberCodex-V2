## Learn

&gt; sends a command's output into a file instead of the screen. It creates the file, or completely replaces whatever was in it.

echo prints text, and echo "text" &gt; file.txt writes that text into file.txt. The file must end up containing exactly the right text, so watch spelling and capitals. Once it matches, reward.txt appears.

## Example

```sh
echo "all good" > status.txt     # status.txt now contains: all good
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

status.txt still says the relay is offline. Replace its contents with exactly: relay ready

1. Check the current contents with cat status.txt.
2. Overwrite it with the new status using echo and &gt;.
3. Read reward.txt.

## Common mistake

Avoid cat sample.txt &gt; sample.txt. Use a separate temporary destination.
