## Learn

whoami identifies the current user. id also shows user and group IDs. Here those identities are simulated and belong only to your learning environment.

The username is a human-readable identity; the numeric UID is what a real Linux kernel uses for ownership checks. Groups provide additional access categories. This environment has a single simulated owner so you can practice commands without changing your computer or another learner’s files.

## Syntax example

```sh
whoami
id
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Run whoami and id. Then read /home/user/operator.txt to collect your dispatch.

## Common mistake

The user shown inside this lab is not your email address, and it is not a login to the website’s server.
