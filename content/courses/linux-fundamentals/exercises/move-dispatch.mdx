## Learn

mv moves or renames a file. Unlike cp, the old name disappears, because it's the same file under a new path.

Renaming and moving are the same operation in Linux: you're changing the path used to reach the file. mv old.txt new.txt renames it, and mv file.txt folder/ moves it into a folder. Afterwards, check that the old name is gone. Once the rename is correct, reward.txt appears with your flag.

## Why it matters

Renaming files is everyday admin work, and knowing the difference between moving and copying avoids lost or duplicated data.

## Example

```sh
mv draft.txt final.txt       # rename a file
mv final.txt reports/        # move it into a folder
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

The incoming report has been approved. Rename incoming.txt to approved.txt, keeping its contents, and collect your reward.

1. Run mv incoming.txt approved.txt.
2. Run ls to check that incoming.txt is gone.
3. Read the reward with cat reward.txt.

## Common mistake

If incoming.txt still exists afterwards, you copied the file instead of moving it.
