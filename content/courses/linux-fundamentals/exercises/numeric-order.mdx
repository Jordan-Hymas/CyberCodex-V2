## Learn

Lexical sorting compares characters, so 10 can appear before 2. sort -n compares numeric values. head then selects the highest-priority item if smaller numbers mean earlier service.

Numbers stored as text can be sorted numerically or lexically. Choose based on what the data represents. Numeric sorting is appropriate for counts and priorities, while lexical sorting may be appropriate for identifiers. Once ordered, select a small slice for inspection.

## Example

```sh
sort -n numbers.txt
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Sort priorities.txt numerically and save the smallest value to first.txt.

## Common mistake

A value that starts with digits is not always semantically a number; a postal code, for example, is an identifier.
