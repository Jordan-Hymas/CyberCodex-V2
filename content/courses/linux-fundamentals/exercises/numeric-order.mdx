## Learn

sort orders lines alphabetically by default, so 10 comes before 2. sort -n sorts by numeric value instead.

Alphabetical sorting compares character by character, which gives surprising results for numbers. Always use -n for numbers. -r reverses the order.

## Example

```sh
sort -n sizes.txt | head -n 1    # smallest number
```

Example filenames illustrate syntax; inspect your mission files before running them.

## Your mission

Find the smallest number in priorities.txt and save just that number to first.txt.

1. Sort the numbers so the smallest comes first. Check your output.
2. Save only the first line to first.txt.

## Common mistake

A value that starts with digits is not always semantically a number; a postal code, for example, is an identifier.
