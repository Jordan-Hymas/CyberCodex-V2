## Learn

### Alphabetical order surprises

By default, `sort` compares lines character by character, like a dictionary. For numbers that gives odd results: `1000` comes before `9`, because the character `1` comes before `9`.

```sh
sort sizes.txt
```

### sort -n compares numbers

`-n` tells `sort` to read each line as a number. Add `-r` to reverse the order, which puts the biggest first.

```sh
sort -n sizes.txt
sort -n -r sizes.txt
```

### Smallest and largest

Combine `sort -n` with `head` or `tail` to pick out the extremes: the smallest number is the first line after sorting, the largest is the last.

```sh
sort -n sizes.txt | head -n 1   # smallest
sort -n sizes.txt | tail -n 1   # largest
```

## Command cheat sheet

- `sort -n FILE`: Sort by numeric value.
- `sort -n -r FILE`: Largest first.
- `sort -n FILE | head -n 1`: The smallest number.

## Common mistake

A value that starts with digits is not always semantically a number; a postal code, for example, is an identifier.
